## 📊 Система масштабирования

### Шрифты
```
getResponsiveFontSize(16, 10, 24)
                      ↓  ↓  ↓
                  базовый мин макс
                  
На 375px (iPhone): 16
На 768px (iPad):   32 (но ограничено max=24)
На 1024px iPad Pro: 43 (но ограничено max=24)
```

### Отступы
```
getResponsivePadding(16)

На 375px: 16
На 768px: 32.6
На 1024px: 43.5
```

## 📚 Новый файл: responsiveUtils.js

Все функции для адаптивности находятся в одном файле:

```bash
src/utils/responsiveUtils.js  ← Главная утилита
```

### Доступные функции:

```javascript
import {
  getResponsiveFontSize(base, min, max),
  getResponsivePadding(base),
  getDeviceType(),              // 'mobile', 'large-tablet', 'tablet'
  getOrientation(),             // 'portrait', 'landscape'
  getButtonDimensions(),        // Размеры для Button
  getCardPadding(),            // Размеры для Card
  getInputDimensions(),        // Размеры для Input
  getGridItemSize(itemsPerRow, gap),
  getSafeAreaPadding(),        // Для notch
} from '../utils/responsiveUtils';
```
