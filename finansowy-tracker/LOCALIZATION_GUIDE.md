## 🌍 Система Автоматической Локализации

Теперь приложение полностью поддерживает автоматический перевод всех элементов, включая новые категории и продукты, которые добавляет пользователь.

### 📋 Как это работает:

#### 1. **Встроенные категории (с ключами локализации)**
Встроенные категории используют поле `nameKey` для ссылки на текст в локалях:
```javascript
{
  id: '1',
  nameKey: 'category_food',  // Ключ для поиска в локалях
  color: '#FF6B6B',
  icon: '🍔',
  type: 'expense'
}
```

При смене языка эти категории автоматически переводятся через функцию `t()` из контекста.

#### 2. **Пользовательские категории (добавленные юзером)**
Когда пользователь добавляет новую категорию, система:
- Сохраняет название (например, "Eat" на английском)
- Автоматически переводит его на другие языки (pl, ru) с помощью функции `tAuto()`
- Кэширует переводы для быстрого доступа

Пример:
```
Пользователь добавляет категорию "Eat":
- En: Eat
- Pl: Jedzenie (автоматически переведено)
- Ru: Еда (автоматически переведено)
```

### 🔧 Основные функции в `src/utils/i18n.js`:

#### `t(key, lang)` - Основная функция локализации
Используется для переводов ключей из локалей.
```javascript
t('App Name', 'ru')  // → "Финансово Трекер"
t('category_food', 'pl')  // → "Jedzenie"
```

#### `tAuto(text, targetLang, sourceLang)` - Автоматический перевод
Переводит динамические значения (названия категорий, продукты и т.д.)
```javascript
tAuto('Eat', 'ru', 'en')  // → "Еда"
tAuto('Food', 'pl', 'en')  // → "Jedzenie"
```

#### `addTranslationToCache(text, translations_map)` - Добавить перевод в кэш
Кэширует переводы для повторного использования.
```javascript
addTranslationToCache('MyFood', {
  'en': 'MyFood',
  'pl': 'MójJedzenie',
  'ru': 'МояЕда'
})
```

### 🎯 Как использовать в компонентах:

#### Для встроенных текстов (из локалей):
```javascript
const { t } = useApp();
<Text>{t('App Name')}</Text>  // Переводит по ключу
```

#### Для названий встроенных категорий:
```javascript
const { getCategoryName, language } = useApp();
<Text>{getCategoryName(category, language)}</Text>
```

#### Для динамических значений (пользовательские категории):
```javascript
const { tAutoTranslate } = useApp();
<Text>{tAutoTranslate(userCategoryName, 'en')}</Text>  // Переводит на текущий язык
```

### 📚 Словарь переводов

Словарь хранится в `autoTranslateMap` в `src/utils/i18n.js` и включает переводы между языками:

- `en_pl` - Английский → Польский
- `en_ru` - Английский → Русский
- `pl_en` - Польский → Английский
- `pl_ru` - Польский → Русский
- `ru_en` - Русский → Английский
- `ru_pl` - Русский → Польский

Если перевода нет в словаре, функция возвращает оригинальный текст.

### 🚀 Как добавить новый перевод:

Если вы хотите добавить перевод для нового слова, отредактируйте `autoTranslateMap` в `src/utils/i18n.js`:

```javascript
const autoTranslateMap = {
  en_ru: {
    'YourNewWord': 'ВашНовоеСлово',
    // ... остальные переводы
  },
  // ... остальные пары языков
}
```

### ⚙️ Как интегрировать Google Translate API (опционально):

Если вы хотите использовать полноценный API перевода вместо встроенного словаря, замените функцию `tAuto()` на:

```javascript
export async function tAuto(text, targetLang = 'pl', sourceLang = 'en') {
  // Реализация с использованием Google Translate API
  // или другого сервиса перевода
}
```

И обновите компоненты для использования асинхронной версии функции.
